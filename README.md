# 2049: Ryan Gosling

2049 — браузерная версия головоломки 2048 в стилистике фильмов с Райаном Гослингом. Игровая сетка, управление, темы, музыка и лидерборд реализованы на чистых HTML, CSS и JavaScript.

## Возможности

- сетка 4×4 с динамическим слиянием плиток;
- набор очков при объединении одинаковых значений;
- появление новых плиток со значениями 2 или 4 после хода;
- завершение партии, когда не осталось доступных ходов;
- отмена последнего хода;
- начало новой партии;
- сохранение состояния партии и результата в `localStorage`;
- локальная таблица лидеров с именем игрока, очками и датой;
- плавная анимация перемещения, слияния и появления плиток;
- клавиатурное управление стрелками;
- свайпы по игровому полю на мобильных устройствах;
- адаптивная компоновка для компьютеров и смартфонов;

## Темы

Фон и саундтрек меняются по достижении определённого значения плитки.

| Значение | Тема |
|---:|---|
| 2 | Ла-Ла Ленд |
| 16 | Бегущий по лезвию 2049 |
| 32 | Драйв |
| 64 | Эта дурацкая любовь |
| 128 | Только бог простит |
| 256 | Место под соснами |
| 512 | Первый человек |
| 1024 | Барби |
| 2048 | Славные парни |

Для плиток 2, 4 и 8 используются отдельные изображения Ла-Ла Ленда. Каждое последующее достижение использует изображение соответствующей темы.

## Музыка

Плеер работает в двух режимах:

- **Музыка по темам** — трек меняется вместе с темой и начинается заново при переходе на новую;
- **Мой плейлист** — можно выбрать песню вручную и переключаться между треками.

Доступны воспроизведение, пауза, название трека и перемотка. Позиции треков сохраняются отдельно в браузере.

Браузер может запрещать автоматическое воспроизведение до первого действия пользователя. Если музыка не началась сразу после загрузки страницы, нажмите кнопку воспроизведения.

## Управление

На компьютере используются клавиши со стрелками.

На телефоне или планшете можно проводить свайпы влево, вправо, вверх или вниз по игровому полю.

Кнопки управления стрелками в интерфейсе скрыты на экранах шириной до 760 px.

## Локальное хранение

Приложение не отправляет данные на сервер. Используются следующие ключи `localStorage`:

- `gosling-2048-game-state` — состояние и счёт партии;
- `gosling-2048-best-score` — лучший результат;
- `gosling-2048-leaderboard` — записи таблицы лидеров;
- `gosling-2048-discovered-values` — впервые открытые значения плиток;
- `gosling-2048-sound` и `gosling-2048-music-paused` — состояние звука;
- `gosling-2048-music-mode` — режим музыки;
- `gosling-2048-playlist-track` — выбранный трек плейлиста;
- `gosling-2048-music-position` — позиции воспроизведения.

Очистка данных сайта в настройках браузера удалит сохранённую игру, рекорды и настройки музыки.

## Запуск

Проект не требует установки пакетов или сборки.

Откройте `index.html` через локальный статический сервер:

```bash
cd 2048-vanilla-js
python3 -m http.server 4173
```

После запуска откройте `http://127.0.0.1:4173/`.
